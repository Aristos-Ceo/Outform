# OUTFORM — Premium Sneaker & Streetwear Store

A modern, editorial-inspired e-commerce storefront concept built around sneaker culture, streetwear, and premium digital retail experiences.

**Live Demo:** https://outform-gamma.vercel.app/  
**Source Code:** https://github.com/Aristos-Ceo/Outform

---

## Overview

OUTFORM is a front-end e-commerce portfolio project designed to explore how a premium sneaker and streetwear brand could translate its identity into a polished online shopping experience.

The project combines a bold visual direction, editorial-style layouts, product discovery, and interactive shopping features to create a storefront that feels cohesive, modern, and intuitive.

From the homepage to the product catalogue, brand directory, shopping bag, and wishlist, the experience is designed to make browsing feel seamless while maintaining a distinctive visual identity.

This project was developed as part of my web development portfolio to demonstrate front-end development, interface design, responsive layouts, and interactive e-commerce functionality.

## Getting Started

You can run the project locally in a few steps.

### 1. Clone the repository

```bash
git clone https://github.com/Aristos-Ceo/Outform.git
```

### 2. Open the project

```bash
cd Outform
```

Open the folder in Visual Studio Code.

### 3. Run locally

Use the **Live Server** extension in VS Code:

1. Open `index.html`.
2. Right-click inside the editor.
3. Select **Open with Live Server**.

A local development server is recommended for loading local assets and testing browser-based functionality.

## Deployment

The project is deployed using Vercel and connected to its GitHub repository.

**Live URL:** https://outform-gamma.vercel.app/

Changes pushed to the connected GitHub branch can trigger automatic deployments through Vercel.

## Important Project Notes

OUTFORM is a front-end portfolio demonstration, not a production-ready commercial e-commerce platform.

- No real payments are processed or verified.
- Bank transfer and card options represent payment preferences; they are not connected to a payment gateway.
- Checkout prepares an order request and hands it off through the configured WhatsApp contact.
- No production authentication or secure customer-account backend is implemented.
- Product information, pricing, sizing, stock, and brand associations are illustrative demo data.
- Newsletter and contact forms use a `mailto` handoff rather than a connected CRM or mailing-list service.
- Local SVG brand artwork is illustrative and should be replaced with approved official assets before commercial use.
- WhatsApp contact details and business configuration should be verified before any real-world deployment.

This project should not be used to collect real customer payments or sensitive customer information.
